# V2 API additions

All paths are beneath `/api/v1`. The [OpenAPI 3.1 operation inventory](openapi.json) is also served by GET /openapi.json. Regenerate it with `npm run docs:api`. Shared Zod schemas supply principal request shapes; business/ownership/state checks remain server-authoritative.

| Domain            | Requests and contracts                                                                                                                                                                                                                                                                                                                                                |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Discovery         | GET /discovery/search: q,lat,lng,radius?,categoryId?,available=true/false,sort=distance/price-asc/price-desc,limit,offset. Returns results,total,radiusKm,expanded,distanceType=STRAIGHT_LINE. Omit radius for 1→2→5→10 km; manual 15/25 allowed. GET /discovery/suggestions?q=...                                                                                    |
| Addresses         | GET/POST /customers/addresses; DELETE /customers/addresses/:id archives an owned address. Address fields: label,recipient,phone,line1,locality,postalCode,latitude,longitude                                                                                                                                                                                          |
| Quote             | POST /delivery/quotes with shopId,addressId. Returns server fee, provider, snapshot, ten-minute expiry and explicit simulation/manual notice. No invented ETA                                                                                                                                                                                                         |
| Checkout          | POST /orders adds fulfillmentType=PICKUP/DELIVERY,quoteId,packingPreferences. Payment method is PICKUP/COD/SIMULATED; shop/fulfillment eligibility is checked. Idempotency-Key required                                                                                                                                                                               |
| Carts             | GET /cart?shopId=... optionally selects a basket. Another shop's items are retained. Checkout clears only its shop                                                                                                                                                                                                                                                    |
| Dispatch          | ADMIN POST /delivery/events: orderId,eventId,status,note plus riderName/code/collected/returned/discardReturned. Status: RIDER_ASSIGNED,RIDER_PICKED_UP,OUT_FOR_DELIVERY,DELIVERED,DELIVERY_FAILED,CANCELLED. Customer code and COD collection are checked for delivery. Failed returns need physical-return confirmation. Event IDs are payload-bound and idempotent |
| Tracking          | GET /delivery/:id/status is customer/merchant/admin scoped. Unsigned /delivery/webhook calls are rejected                                                                                                                                                                                                                                                             |
| Offline billing   | POST /merchant/offline-sales with Idempotency-Key and shopId,paymentMethod=CASH/UPI/CARD,items[{variantId,quantity}]. GET lists owned snapshots. Server prices and unreserved inventory are authoritative                                                                                                                                                             |
| Variants          | POST /merchant/products/:id/variants: label,pricePaise,stockMilli. PATCH /merchant/variants/:id: label,pricePaise,lowStockMilli. Daily price edits do not alter old order snapshots                                                                                                                                                                                   |
| Catalogue         | Creation adds brand,sku,keywords and MILLILITER. Product PATCH adds brand,sku,keywords,specifications,freshnessInstructions                                                                                                                                                                                                                                           |
| Shop settings     | PATCH /merchant/shops/:id adds deliveryEnabled,codEnabled,deliveryRadiusKm,pickupInstructions. PUT /merchant/shops/:id/hours replaces day (0–6),opens/closes HH:mm entries                                                                                                                                                                                            |
| Reports           | GET /merchant/reports?days=1..366: India business-day online/offline gross sales, fees, merchant payable, daily series, top products. /merchant/reports.csv exports offline sales only                                                                                                                                                                                |
| Saved items       | GET /customers/favorites; PUT/DELETE /customers/favorites/:shopId. Wishlist uses corresponding /customers/wishlist/:productId routes                                                                                                                                                                                                                                  |
| Lists/reorder     | GET/POST /customers/shopping-lists; PATCH /customers/shopping-lists/:id with name,items[{name,quantity}]. POST /customers/orders/:id/reorder checks current stock and prices and keeps other shop carts                                                                                                                                                               |
| Reviews           | POST /customers/reviews with productId,orderId,rating (1–5),body. A completed owning purchase is verified. GET lists own reviews                                                                                                                                                                                                                                      |
| Support           | GET/POST /support/tickets: authorized optional orderId,subject,body. ADMIN PATCH /admin/support/:id: status,resolution; audit logged                                                                                                                                                                                                                                  |
| Refunds           | GET/POST /customers/refunds: orderId,amountPaise,reason. Transactional paid-amount/remaining-claim checks. ADMIN GET /admin/refunds; PATCH /admin/refunds/:id: action=APPROVE/REJECT/CONFIRM_MANUAL_REFUND,resolution. Cash approval becomes MANUAL_REQUIRED, not refunded. Reimbursement confirmation and simulations are separate states                            |
| Commissions       | ADMIN GET/POST /admin/commissions: optional shopId/categoryId,basisPoints (0–10000),minimumFeePaise,waived. Shop override > category > global. Changes affect new orders only; fees cap at merchandise value                                                                                                                                                          |
| Admin reports     | GET /admin/analytics separates GMV, fees, recorded refunds, quoted delivery charges and net fee revenue. GET /admin/deliveries; GET /admin/audit                                                                                                                                                                                                                      |
| Preferences/gates | PATCH /users/notification-preferences: orderUpdates,lowStock,marketing. GET /features advertises intentionally disabled modules                                                                                                                                                                                                                                       |

Money is INR paise, quantities thousandths of the displayed unit. Customer locations/addresses are private. Delivery and refund mutations are audited. No raw client payment result is proof of payment.
